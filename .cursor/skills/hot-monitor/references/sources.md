# 去哪里找

近 7 天、能看出发布时间的材料才留下来。搜索结果页本身不是来源，点进文章后再看域名。

## 优先看的公开页面

- RSS 或官网博客：机器之心 `jiqizhixin.com`、量子位 `qbitai.com`、OpenAI、Anthropic、Google AI、Hugging Face
- Hacker News 里和人工智能相关的帖子
- GitHub 上近 7 天、主题与 LLM 相关的仓库或发行说明
- arXiv 的 cs.AI、cs.CL、cs.LG
- 网页搜索。默认话题是人工智能。用户给了词，就用那些词搜，不要改去搜别的热词

关键词和发现方向的搜索不要依赖 Google 这一条路。用你手头能打开的搜索即可，结果仍要落到下面的权威域名上。

## 什么能单独成一条

- 过了下面 X 门槛的帖子可以单独出现。
- 只有一条 Hacker News 或只有一条 GitHub，且没有第二个不同来源时，不进热点和日报。
- 搜索结果只保留权威域名：官方域名、已知媒体、机器之心、量子位。名单在 [trust.md](trust.md)。
- 微博热搜、B 站热门不进热点和发现。用户明确要看热搜时另起一节。

## X

拿不到浏览量或粉丝数时，只保留官方账号。官方账号见 [trust.md](trust.md)。

非官方账号要同时满足：粉丝不少于 10 万，浏览量不少于 1000。浏览量缺失则丢掉。蓝标不能代替这两条。

## 合并成一条故事

同一件事收成一条，来源都留下。

- 同一个 `http` 地址只留一次。`http` 与 `https`、`www` 与否、常见跟踪参数视为同一条。
- 同一条推文只按帖子编号合并。标题像，也不能把推文并进新闻，或把新闻并进推文。
- B 站同一 BV 号是一条。
- 其他来源标题明显是同一事件时可以合并。拿不准就分成两条，不要猜。

## 收集失败时

某一类打不开，其余继续。回答最后写「没有查到：<来源名>」。不要用训练记忆里的旧新闻填上近 7 天的空位。
